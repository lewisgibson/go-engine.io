# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository, please report it through a
[private security advisory](https://github.com/lewisgibson/go-engine.io/security/advisories/new)
rather than filing a public issue.

I respond within 72 hours. Please do not disclose the issue publicly until a fix
is in place.

## Supported Versions

Only the latest release on the `main` branch receives security updates. Older
tags and branches are not maintained.
